GPU 記憶體階層與 roofline：為什麼有些 kernel 再怎麼優化都不會變快

這個系列裡每一個效能數字最後都是記憶體數字——decode 慢是因為每個 token 都要讀一遍權重、KV cache 是容量上限、MoE 是通訊問題、量化有用是因為位元變少。這一天把底下那個模型寫出來：階層長什麼樣、roofline 怎麼決定一個 kernel 是被算力還是被記憶體卡住，以及 tiling（包含 FlashAttention）為什麼是唯一能提高運算密度的辦法。
